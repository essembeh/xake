# Xake — Langues (anglais, français)

> Interface disponible en anglais et en français. Anglais par défaut, défaut paramétrable par
> le service, et chaque utilisateur choisit sa langue dans les réglages, comme le thème.
>
> Statut : **implémenté**. Rédigé le 2026-10-28.

## 1. Mécanisme

- Traduction **côté client** : `static/js/i18n.js` porte les dictionnaires `en` et `fr` et
  `t(clé, paramètres)`. L'anglais est la référence : une clé absente en français retombe sur
  l'anglais, puis sur la clé elle-même (visible, donc repérable).
- Le HTML statique est écrit en anglais et porte ses clés (`data-i18n`, `data-i18n-title`,
  `data-i18n-aria`, `data-i18n-placeholder`), retraduites à chaque changement de langue.
- Les textes générés en JS passent tous par `t()`. Noms des camps via `sideName()`.
- Les libellés des thèmes, plateaux et jugements (`?!`, `?`, `??`) sont des clés
  (`theme.*`, `board.*`, `judgement.*`), pas des chaînes en dur dans les modules.

## 2. Langue par défaut du service

- `XAKE_DEFAULT_LANGUAGE` (`en` | `fr`, défaut `en`), validé par Pydantic : une valeur inconnue
  empêche le démarrage plutôt que de servir une langue inattendue.
- Transmis au front par `GET /config.js` (`window.XAKE_CONFIG = {"defaultLanguage": "en"}`),
  chargé en `<script>` synchrone avant `main.js` : pas de flash dans la mauvaise langue, pas
  d'appel API avant le premier rendu. `Cache-Control: no-cache` pour qu'un changement de valeur
  soit pris en compte ; le service worker (network-first) le met en cache pour le hors-ligne.
- Chart Helm : `xake.defaultLanguage` → `XAKE_DEFAULT_LANGUAGE`.

## 3. Choix utilisateur

- Réglages → « Language / Langue » (English / Français), stocké dans `prefs.language` du
  `localStorage`. `null` = suivre le défaut du service, donc changer `XAKE_DEFAULT_LANGUAGE`
  touche tous les utilisateurs qui n'ont jamais choisi.
- `<html lang>` suit la langue (lecteurs d'écran, césure). Les dates de la liste des parties
  sont formatées dans la langue choisie.

## 4. Limites

- La notation des coups reste en SAN anglaise (`Nf3`) dans les deux langues, comme sur
  Lichess ; pas de notation française (`Cf3`).
- Le manifest PWA (nom, description) est en anglais : il est lu à l'installation, avant tout
  choix de langue.
- Ajouter une langue = un dictionnaire dans `i18n.js` + une entrée dans `LANGUAGES` + la
  valeur dans le `Literal` de `default_language`.
